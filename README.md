# Vellora Hotel Chatbot

A group academic AI project focused on developing a chatbot for **Vellora Hotels and Resorts**. The chatbot was designed to assist guests with bookings, room information, amenities, support requests, FAQs, and complaint handling.

## Project Overview

This chatbot was created to improve guest interaction and provide quick digital support in the hospitality domain. It acts like a virtual concierge, helping users before, during, and after their hotel stay through a structured conversational flow.

## Features

- Booking-related inquiry support
- Room type and amenities information
- FAQ handling
- Complaint and report submission
- Support and troubleshooting paths
- Fallback/error-handling flow
- Option for users to continue asking questions
- Hospitality-focused chatbot design

## Tools and Technologies Used
